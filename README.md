# Diabetic Retinopathy Detection

A deep learning-based project for detecting diabetic retinopathy from retinal fundus images.

## Project Overview

This project uses a trained deep learning model to classify retinal images for diabetic retinopathy.

The project includes:

- Deep learning model training
- Retinal image preprocessing
- Model prediction
- Streamlit web interface
- Model evaluation and performance analysis

## Main Files

- `train_retinopathy_v2.py` - Main model training script
- `predict_image.py` - Image prediction functionality
- `retinopathy_web_app.py` - Streamlit web application
- `retinopathy_output_v2/` - V2 model outputs and evaluation results

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Streamlit
- Pillow
- Matplotlib
- Scikit-learn
